This release adds desktop music playlists and creator updates, remembers comic directory sorting, and improves audio-device switching.

## Feature

- Create desktop music playlists from favorite songs, reorder their tracks, and play a whole playlist or start from any song.
- Browse new Bilibili uploads grouped by favorite creator in the desktop Updates tab, mark videos as seen or undo that action, and sync update lists and seen status across devices.

## Improvement

- Remember each favorite comic's directory sort order on desktop while keeping ascending order as the default.

## Fix

- Recover automatically when audio outputs change or become temporarily unavailable, including repeated headphone connections on Windows, while preserving music playback position and pause state.
- Prevent audio format errors when switching between output devices with different sample rates.

本次更新新增桌面端音乐歌单和 UP 主视频更新，记住漫画目录排序，并改进音频设备切换体验。

- 桌面端支持将收藏歌曲加入歌单、调整歌曲顺序，并播放整个歌单或从任意歌曲开始播放。

- 桌面端分别记住每本收藏漫画的目录排序，默认仍为正序。

## Fix

- 音频输出切换或暂时不可用时自动恢复，包括 Windows 上反复插拔耳机的情况，并保留音乐播放位置和暂停状态。
- 修复切换到不同采样率的音频输出设备时可能出现的音频格式错误。
