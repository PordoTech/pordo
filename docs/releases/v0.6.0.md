## Feature

- Search Bilibili videos and creators, sign in by scanning a QR code, and play videos directly.
- Control Bilibili quality and parts from bottom-right menus, with 1080P preferred, authorized fallback qualities, and playback position and pause state preserved during quality changes.
- Favorite Bilibili creators, browse their uploads, and sync creator favorites across desktop devices.

## Improvement

- Rebrand the app as Pordo while keeping existing installations, settings, favorites, and history.
- Sync reading and playback progress when leaving the page or closing the app, and download only changed device files through WebDAV instead of polling every five minutes.
- Check Komiic favorites for updates in small batches without downloading complete chapter lists, and check other comic sources concurrently with bounded waits.
- Make video search cards more compact, align comic tabs with music and video tabs, and use consistent icon-only back buttons.
- Simplify Bilibili sign-in messages and show the sign-out button only after signing in.

## Fix

- Fix Bilibili searches failing with a duplicate cover field error.
- Fix Windows window resizing feeding back into repeated size changes and freezing the app.
- Make the home page's continue-watching and continue-listening card hover effects visible over cover images.
- Report cloud traffic quota errors accurately when a connection test succeeds but syncing fails.

Windows users upgrading from v0.5.1 or earlier should install this version manually once from [Releases](https://github.com/PordoTech/pordo/releases/tag/v0.6.0); subsequent updates use the new repository address.
