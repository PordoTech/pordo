## Feature

- Sync desktop playlists, including their names, online tracks, and track order.
- Sync local lyrics for favorite songs across desktop devices and switch between synced versions in the lyrics menu.
- Use the existing credential sync option to share encrypted Bilibili sessions and Komiic accounts and sessions across desktop devices.

## Improvement

- Keep desktop credentials in a local file so macOS can use them without Keychain prompts.
- Apply playback speed to the current video and start each new video at normal speed.

## Fix

- Prevent missing local music records from being uploaded as deletions and recover favorites still available on a device.
